# 🎙️ Raphael Voice Assistant (ราฟาเอล)
> **AI Voice Assistant & Desktop Companion สำหรับควบคุมระบบปฏิบัติการ Windows**

**Raphael (ราฟาเอล)** คือผู้ช่วย AI สั่งงานด้วยเสียงที่ถูกออกแบบมาให้ทำงานบน Windows อย่างเรียบหรู ปลอดภัย และแม่นยำ ด้วยสถาปัตยกรรม Hybrid (ประมวลผลคำสั่งด่วนด้วย Rule-based + AI Reasoning ผ่าน LLM) 

---

## 🌟 คุณสมบัติเด่น (Key Features)

- 🗣️ **การจดจำและตอบสนองภาษาไทย:** สั่งงานภาษาไทยผ่านเสียงได้อย่างเป็นธรรมชาติ พร้อมระบบโต้ตอบกลับด้วยเสียง (TTS)
- 🖥️ **การควบคุมระบบ Windows (OS Control):** เปิด/ปิด โปรแกรมระบบ เช่น File Explorer, Settings, Control Panel, Calculator โดยไม่กระทบ Taskbar หรือ Desktop
- 🧹 **ระบบจัดการหน้าต่างอัจฉริยะ (Window Management):** รองรับคำสั่งเคลียร์หน้าจอ ปิดหน้าต่างที่ไม่เกี่ยวข้อง และคงไว้เฉพาะโปรแกรมทำงาน เช่น VS Code หรือ Terminal
- 🎵 **ควบคุมสื่อบันเทิง:** ค้นหาและเล่นเพลงบน YouTube, เพิ่ม/ลด/ปิดเสียง, และควบคุมการเล่นเพลง
- 📝 **จดโน้ต & บันทึกข้อความ:** สั่งจดข้อความภาษาไทยลง Notepad หรือเซฟลงไฟล์ข้อความอัตโนมัติ
- ⏰ **ระบบแจ้งเตือน (Reminder System):** ตั้งเวลาเตือนความจำ พร้อมระบบแจ้งเตือนเมื่อถึงกำหนดเวลา
- 🛡️ **ระบบความปลอดภัยสูง (Safety & Confirmations):** มีระบบยืนยันตัวตน (Confirmation) ก่อนสั่งงานความเสี่ยงสูง เช่น การปิดเครื่อง หรือรีสตาร์ท PC
- 🌐 **ค้นหาข้อมูลสด (Live Search Grounding):** ดึงข้อมูลสภาพอากาศ ข่าว และความรู้ปัจจุบันผ่าน Google Search

## ⚙️ ข้อแนะนำในการใช้งาน (Best Practices)

1. **การสั่งงานหลายรายการ:** ในปัจจุบันโปรเจกต์ถูกออกแบบให้ประมวลผล **"1 คำสั่งต่อประโยค"** เพื่อความแม่นยำสูงสุด หากสั่งหลายคำสั่งพร้อมกัน ราฟาเอลจะแจ้งเตือนให้รบกวนสั่งทีละรายการ
2. **ความปลอดภัยของระบบปิดเครื่อง:** คำสั่ง `shutdown_pc` หรือ `restart_pc` จะต้องมีการพูดคำว่า **"ยืนยัน"** อีกครั้งเพื่อป้องกันอุบัติเหตุ
3. **การเปิดไฟล์ภาษาไทย:** โปรเจกต์ใช้ไลบรารี `pyperclip` ในการคัดลอกและวางข้อความภาษาไทย เพื่อหลีกเลี่ยงปัญหาพิมพ์ภาษาไทยผิดพลาดบน Windows Keyboard layout
